TV ekranı

Menü TV ekranına sığmazsa otomatik olarak sayfalara bölünür ve sırayla gösterilir. TV, yayınladığınız değişiklikleri birkaç dakika içinde kendiliğinden alır.

TV'de geçecek resimler

Menü sayfaları bir tur dönünce, sıradaki resim tam ekran gösterilir, sonra menü baştan başlar. Kampanya, yeni ürün, etkinlik görselleri için. En iyi sonuç için yatay (16:9) resim kullanın.

GitHub bağlantısı (bir kerelik)

Menünüz GitHub'daki deponuzda menu.json dosyası olarak durur. "Yayınla" dediğinizde bu panel dosyayı günceller; site 1-2 dakika içinde yenilenir. Anahtar sadece bu cihazın tarayıcısında saklanır.

Anahtar (token) nasıl alınır?
  1. GitHub'a girin → sağ üstte profil resmi → Settings → en altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Ad: Menü paneli. Süre (Expiration): en uzun seçeneği seçin; süresi dolunca aynı adımlarla yenisini alırsınız.
  3. Repository access → Only select repositories → menü deponuzu seçin.
  4. Permissions → Contents → Read and write.
  5. Generate token'a basın, çıkan github_pat_… ile başlayan anahtarı kopyalayıp yukarıya yapıştırın.

Yedek

Tüm eski sürümler GitHub'da da saklanır (depo → menu.json → History).
